# 严禁出现任何提示弹窗与浮动向导 (Strict Zero Floating Popups & Banners)

1. **绝对禁止 DOM 弹窗/横幅/浮动把手**：
   - 严禁在任何 3D 物理、化学、光学、力学实验中注入悬浮提示弹窗、顶部步骤向导 Banner、悬浮卡片、Toast、气泡提示或非三维实体的文字按钮把手。
   - 视窗必须保持纯净三维物理台面，绝对禁止遮挡视线。

2. **纯三维实体交互原则**：
   - 所有实验交互（拖拽、套挂、向下取下、平衡稳定、绘制标记）必须完全基于 3D 模型实体本身、真实物理求解器动力学与原生 3D 材质/光效。
